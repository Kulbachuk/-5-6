Лабораторна робота №5-6: Проєктування UI у Django та Flask

Цей репозиторій містить навчальні веб-додатки з аналогічною предметною областю («Каталог IT-літератури»), реалізовані на двох популярних Python-фреймворках — Django та Flask. Проєкт демонструє побудову користувацького інтерфейсу, роботу з шаблонами, успадкуванням, передачею контексту, декларативною валідацією форм, CSRF-захистом та flash-повідомленнями.

🛠️ Структура проєкту

лр5/
├── django_project/       # Додаток на Django (MVT, DTL)
│   ├── config/           # Головна конфігурація та urls.py
│   ├── books/            # Додаток каталогу книг (views, forms, urls)
│   │   └── templates/    # Шаблони DTL з успадкуванням
│   └── manage.py
│
├── flask_project/        # Додаток на Flask (Flask-WTF, Jinja2)
│   ├── app.py            # Точка входу та маршрутизація
│   ├── forms.py          # Форми Flask-WTF з валідацією
│   └── templates/        # Шаблони Jinja2 з макросами
│
├── requirements.txt      # Залежності Python
└── README.md             # Інструкція з запуску


🚀 Швидкий запуск

1. Клонування та налаштування середовища

Відкрийте термінал у кореневій папці проєкту та створіть віртуальне середовище:

# Створення venv
python -m venv venv

# Активація у Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# Активація у Linux / macOS:
source venv/bin/activate


2. Встановлення залежностей

pip install -r requirements.txt


⚙️ Запуск додатків

🟢 1. Запуск Django-проєкту

cd django_project
python manage.py runserver


Головна сторінка: http://127.0.0.1:8000/

Додавання книги (Форма): http://127.0.0.1:8000/add/

🌶️ 2. Запуск Flask-проєкту

Відкрийте окремий термінал або зупиніть Django (Ctrl + C):

cd flask_project
python app.py


Головна сторінка: http://127.0.0.1:5001/

Додавання книги (Форма): http://127.0.0.1:5001/add

🔒 Особливості безпеки та реалізації

CSRF-Захист:

Django: Використовується вбудований middleware та тег {% csrf_token %} у кожній POST-формі.

Flask: Реалізовано через розширення Flask-WTF, ключ SECRET_KEY та токен form.hidden_tag().

Серверна Валідація:

Перевірка обов'язковості заповнення, форматів e-mail та кастомна бізнес-логіка (мінімальна кількість слів у описі) перевіряються виключно на сервері.

XSS Захист:

Шаблонізатори DTL та Jinja2 застосовують автоматичне екранування символів (Auto-escaping).
